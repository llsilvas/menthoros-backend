# AI-Assisted Code Generation for Menthoros Backend

This guide explains how to request and validate code generated by Claude or other AI models for the menthoros-backend.

## Quick Start

### When Requesting AI-Generated Code

Provide this context to Claude:

```
You are generating code for the Menthoros Backend.

MANDATORY: Follow EVERY rule from apps/menthoros-backend/CLAUDE.md

Key sections to follow:
1. Controller Standards (layered architecture, @PreAuthorize, etc.)
2. Mapper Standards (null handling)
3. Service Standards (Idempotency documentation, Input Validation, Logging)
4. DTO & Records Standards (use records, not classes)

Reference templates:
- Controller: docs/CONTROLLER_TEMPLATE.java
- Service: docs/SERVICE_TEMPLATE.java

Test with: ./mvnw clean test
```

### Example Prompt

```
Generate a new controller and service for the "Treino Realizado" resource.

Requirements:
- Endpoints: GET /api/v1/treinos-realizados, POST, PUT /{id}, DELETE /{id}, GET /{id}
- DTOs: TreinoRealizadoInputDto (input) and TreinoRealizadoOutputDto (output)

- Controller template: docs/CONTROLLER_TEMPLATE.java
- Service template: docs/SERVICE_TEMPLATE.java

```

## Templates

### Controller Template

**File:** `docs/CONTROLLER_TEMPLATE.java`

Use this as a reference for all new controller implementations.

**Key points:**
- Marked with `@RequireTenant` annotation
- Injects `Service` + `Mapper` (never `Repository`)
- All write endpoints have `@PreAuthorize`
- Every method has `@Operation` + `@ApiResponses`
- Returns `ResponseEntity<OutputDto>` (never `Map`)

### Service Template

**File:** `docs/SERVICE_TEMPLATE.java`

Use this as a reference for all new service implementations.

**Key points:**
- Every public method documents:
  - `**Idempotent:** YES/NO`
  - `**Side Effects:** ...`
  - `**Tenant-aware:** YES/NO`
- Input validation (defensive)
- Logging entry/exit with context
- Uses `TenantContext.getRequiredTenantId()` for tenant isolation

## Code Validation Checklist

Before merging AI-generated code, verify these patterns:

### Controllers

- [ ] Only `Service` and `Mapper` injected (no `Repository`)
- [ ] All write endpoints (@POST/@PUT/@DELETE) have `@PreAuthorize`
- [ ] Every method has `@Operation` summary
- [ ] Every method has complete `@ApiResponses` listing all HTTP status codes
- [ ] Returns `ResponseEntity<OutputDto>` (never `Map<String, Object>`)
- [ ] Input DTOs validated with `@Valid`
- [ ] Controller marked with `@RequireTenant` annotation

### Services

- [ ] Every public method has JavaDoc with:
  - [ ] Brief description
  - [ ] `**Idempotent:** YES/NO`
  - [ ] `**Side Effects:** ...`
  - [ ] `**Tenant-aware:** YES/NO`
- [ ] Validates inputs (defensive, beyond DTO validations)
- [ ] Logs entry/exit with context (ID, tenant, operation result)
- [ ] Uses `TenantContext.getRequiredTenantId()` for tenant isolation
- [ ] `@Transactional` on write methods
- [ ] `@Transactional(readOnly = true)` on read methods

### DTOs

- [ ] All DTOs are `record` (not `class`)
- [ ] Input DTOs have validation annotations (`@NotNull`, `@Size`, `@Email`, etc.)
- [ ] Output DTOs have `@JsonInclude(NON_NULL)`
- [ ] Every field has `@Schema(description = "...")`

### Mappers

- [ ] Null checks on inputs (throws `IllegalArgumentException`)
- [ ] No silent null returns
- [ ] Documented expectations (input/output types)

### Tests

- [ ] `./mvnw clean test` passes (100% success)
- [ ] No compilation errors
- [ ] No test failures

## Automated Validation

### Run Full Test Suite

```bash
cd apps/menthoros-backend
./mvnw clean test
```

### Check for Common Issues

```bash
# 1. Controllers injecting Repository directly
grep -r "@Autowired.*Repository\|private.*Repository" \
  src/main/java/br/com/menthoros/backend/controller/

# 2. DTOs as mutable classes (should be records)
grep -r "public class.*OutputDto\|public class.*InputDto" \
  src/main/java/br/com/menthoros/backend/dto/

# 3. Missing @PreAuthorize on write endpoints
grep -B2 "@PostMapping\|@PutMapping\|@DeleteMapping" \
  src/main/java/br/com/menthoros/backend/controller/*.java \
  | grep -v "@PreAuthorize"

# 4. Unsafe mappers (missing null checks)
grep -A5 "public.*toOutputDto\|public.*toDomain" \
  src/main/java/br/com/menthoros/backend/mapper/*.java \
  | grep -v "if.*null\|throw.*Illegal"
```

## Red Flags - Reject Code With

```
❌ Controllers injecting Repository directly
❌ DTOs as mutable classes (not records)
❌ Missing @PreAuthorize on write endpoints
❌ Raw Map<String, Object> returns
❌ Try/catch blocks for HTTP error handling (should use GlobalExceptionHandler)
❌ Mappers without null checks
❌ Services missing Idempotency documentation
❌ Services using TenantContext without @RequireTenant on controller
❌ Test failures or compilation errors
```

## Common Issues & Fixes

### Issue: DTOs as Classes

**Generated code:**
```java
@Data
@NoArgsConstructor
@AllArgsConstructor
public class AtividadeStravaOutputDto {
    private UUID id;
    private String descricao;
}
```

**Fix:** Convert to record:
```java
@JsonInclude(JsonInclude.Include.NON_NULL)
@Schema(description = "Atividade Strava data")
public record AtividadeStravaOutputDto(
    @Schema(description = "Unique ID")
    UUID id,
    
    @Schema(description = "Description")
    String descricao
) {}
```

### Issue: Missing Null Checks in Mappers

**Generated code:**
```java
public AtividadeStravaOutputDto toOutputDto(AtividadeStrava entity) {
    return new AtividadeStravaOutputDto(
        entity.getId(),
        entity.getDescricao()  // ❌ What if entity is null?
    );
}
```

**Fix:** Add null check:
```java
public AtividadeStravaOutputDto toOutputDto(AtividadeStrava entity) {
    if (entity == null) {
        throw new IllegalArgumentException("AtividadeStrava entity cannot be null");
    }
    return new AtividadeStravaOutputDto(
        entity.getId(),
        entity.getDescricao()
    );
}
```

### Issue: Missing @PreAuthorize

**Generated code:**
```java
@PostMapping
public ResponseEntity<AtividadeStravaOutputDto> criar(
    @Valid @RequestBody AtividadeStravaInputDto input) {
    // ❌ Missing @PreAuthorize!
    return ResponseEntity.status(CREATED).body(...);
}
```

**Fix:** Add security:
```java
@PostMapping
@PreAuthorize("hasAnyRole('TECNICO', 'ADMIN')")
public ResponseEntity<AtividadeStravaOutputDto> criar(
    @Valid @RequestBody AtividadeStravaInputDto input) {
    return ResponseEntity.status(CREATED).body(...);
}
```
